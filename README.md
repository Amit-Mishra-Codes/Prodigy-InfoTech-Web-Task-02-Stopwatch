# Prodigy InfoTech Web Development Task 2 — Stopwatch

A responsive stopwatch web application made with HTML, CSS, and vanilla JavaScript.

## Features
- Start, pause, resume, and reset controls
- Lap recording with elapsed time and individual lap duration
- Best lap highlight and lap count
- Responsive mobile and desktop layout
- Uses `performance.now()` for timing

## Technologies
HTML5, CSS3, JavaScript.

## Run
Open `index.html` in a modern web browser. No installation or external packages are required.

## Internship task
Build a stopwatch web application with start, pause, and reset functions and the ability to track and display lap times.
